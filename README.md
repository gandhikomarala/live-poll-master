# LivePoll Studio — Real-Time Audience Polling & Analytics

Interactive audience voting and survey platform with instant vote tallying, bar/donut visualization, QR code joining, exportable analytics CSV, and anti-tamper ballot verification.

## Product Highlights
- **Domain**: SaaS
- **Visual Theme**: Electric Indigo & Aurora Mint
- **State Persistence**: Browser localStorage & FastAPI microservices
- **Zero-Dependency Web Client**: Works seamlessly on GitHub Pages

## Architecture & Quick Start
```bash
# Run Tests
pytest tests/

# Docker Deployment
docker-compose up -d --build
```
